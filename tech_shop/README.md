Система управления магазином электроники, реализованная как desktop-приложение. Позволяет вести каталог, оформлять продажи, управлять складом, обрабатывать возвраты и собирать ПК на заказ.


### Требования
- **Python 3.14**
- Docker & Docker Compose
- GNU Make

### Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone git@github.com:laptevpavel2007-cloud/osnovi_razrabotki.git
   cd tech_shop

2. Установите с TestPyPi
   ```bash
   pip install -i https://test.pypi.org/simple/ tech-shop
