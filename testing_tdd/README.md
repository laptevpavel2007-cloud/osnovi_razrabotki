# Проект НДФЛ: Автоматизация и TDD

Данный проект реализует расчёт налога на доходы физических лиц (НДФЛ) по прогрессивной шкале. Решение демонстрирует подход к управлению окружением, зависимостями и качеством кода с использованием `Make` как единой точки входа.


## Быстрый старт

Все действия автоматизированы.:

```bash
# Запуск полного цикла проверок (создаст venv, установит пакеты, проверит код, запустит тесты)
make check

# Если нужно только отформатировать код:
make format

# Если нужно только запустить тесты:
make test
